# 🏆 比赛管理与筛选系统

一个轻量的「比赛信息收集 + 标签筛选」Web 系统。用浏览器录入或批量导入比赛信息，自动打标签，并支持按级别、类型、名称、日期快速筛选，还能一键生成公网地址分享给同学。

---

## 一、项目能解决什么问题

- **信息散乱**：比赛通知分散在各个网站、群聊、Excel 里，找起来费劲。
- **整理靠手工**：手动抄录比赛名称、时间、主办方，容易漏、容易重复。
- **筛选靠肉眼**：想找「国家级 + 数学建模」或「未来 60 天内报名截止」的比赛，只能一行行看。

本系统把这些痛点集中解决：

1. 用统一的表单 / Excel 模板把比赛**结构化沉淀**到本地 SQLite 数据库；
2. 依据关键词规则**自动推荐标签**（数学建模、人工智能、国家级、高奖金……）；
3. 按**标签组合 + 名称 + 日期范围**一键筛选，并**自动去重**；
4. 支持 `cloudflared` 公网隧道，**一键把本地系统分享到公网**，无需服务器和部署。

## 二、主要功能

| 功能 | 说明 |
| --- | --- |
| ➕ 录入比赛信息 | 弹窗表单录入：名称、级别、报名时间、赛道、主办/承办、报名链接；随级别动态生成比赛时间字段 |
| 📥 Excel/CSV 批量导入 | 上传文件后**自动定位表头、映射字段、解析时间、推荐标签、检测重复**，先预览再导入 |
| 📄 模板下载 | 一键下载标准模板 `竞赛调研模板.xls` |
| 🏷 自动标签推荐 | 根据名称/级别/赛道/主办方等文本，按规则推荐标签，可手动增删 |
| 🔎 多条件筛选 | 按「比赛级别 / 比赛类型」标签多选组合筛选（AND 逻辑） |
| 🔍 搜索 | 按比赛名称关键字搜索；按日期搜索「选定日期起 60 天内」的比赛 |
| 📊 统计面板 | 实时显示比赛总数、标签种类数、当前筛选结果数 |
| 🗑 删除比赛 | 卡片右上角一键删除 |
| 💾 数据持久化 | 全部数据存入本地 `competitions.db`（SQLite），重启不丢 |
| 🌐 公网分享 | `start_tunnel.py` 调用 `cloudflared` 生成 `https://xxx.trycloudflare.com` 地址，任何人可访问 |

**技术栈**：Python + Flask + SQLite + openpyxl / xlrd + 原生 HTML/JS（单文件前端）。

## 四、安装方法

### 方式 A：零安装（推荐，仓库已内置依赖）

项目内 `pylibs/` 已打包好运行所需的全部第三方库，**无需 pip 安装**。

1. 安装 Python 3.9+（建议 3.10 ~ 3.12），安装时勾选 *Add Python to PATH*；
2. 下载 / 克隆本仓库；
3. 直接运行（见第五节）。

```bash
git clone https://github.com/<your-name>/<your-repo>.git
cd <your-repo>
```

### 方式 B：自行安装依赖

若删除或未包含 `pylibs/`，安装以下依赖即可：

```bash
pip install flask openpyxl xlrd
```

> 说明：`server.py` 会优先从项目内 `pylibs/` 加载依赖，找不到再退回系统环境，因此两种方式都可运行。

## 五、使用方法

### 1. 启动本地服务

```bash
python server.py
```

浏览器打开 **http://127.0.0.1:8765** 即可使用。
（可用环境变量 `HOST` / `PORT` 修改监听地址与端口，默认 `127.0.0.1:8765`。）

### 2. 一键启动（本地服务 + 公网隧道）

Windows 下双击 **`start.bat`**，会依次启动 `server.py` 与 `start_tunnel.py`。
或手动分两步：

```bash
python server.py        # 终端 1：本地服务
python start_tunnel.py  # 终端 2：公网隧道（需先启动 server.py）
```

`start_tunnel.py` 会打印一个形如 `https://xxxx-xxxx.trycloudflare.com` 的**公网地址**，可发给任何人访问（隧道地址每次重启会变，本地数据不受影响；两个窗口保持不关闭）。

### 3. 录入一条比赛

1. 点击 **➕ 录入比赛信息**；
2. 填写「赛事名称」（必填）、「赛事级别」、「报名时间」（可选“月/日”或“月”精度）等；
3. 系统实时**推荐标签**，点标签即可选中，也可自定义输入；
4. 选择级别后会自动出现对应比赛时间字段（见下）；
5. 点击保存。若名称与已有比赛重复，会提示并阻止重复录入。

### 4. 批量导入

1. 点击 **➕ 录入比赛信息** → 弹窗底部 **📥 批量导入**（或下载 **模板** 填写）；
2. 选择 `.xlsx / .xls / .csv` 文件；
3. 系统解析并弹出**预览表**：显示解析到的名称、级别、时间、赛道、主办、标签，以及每行「新导入 / 重复跳过」状态；
4. 确认无误后点击导入，重复数据自动跳过。

### 5. 筛选与搜索

- **按标签筛选**：顶部「🏆 比赛级别」「📚 比赛类型」下拉里点选标签（可多选，取交集），已选条件显示在右侧，可点 ✕ 移除或「清除筛选」；
- **搜索比赛**：输入名称关键字即时过滤；选择日期则显示「该日期起 60 天内」有比赛/报名时间的记录；
- 顶部统计卡片实时更新：比赛总数 / 标签种类 / 当前筛选结果。

## 七、API 接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 返回前端页面 |
| GET | `/api/competitions` | 获取全部比赛 |
| POST | `/api/competitions` | 新增一条比赛（重名返回 409） |
| DELETE | `/api/competitions/<id>` | 删除指定比赛 |
| POST | `/api/competitions/batch` | 批量新增（自动跳过重名） |
| POST | `/api/excel/parse` | 上传 Excel/CSV，返回解析预览 |
| GET | `/api/excel/template` | 下载导入模板 `竞赛调研模板.xls` |

## 八、常见问题

- **页面提示「无法连接服务器」**：请确认 `server.py` 已启动，且端口（默认 8765）未被占用。
- **改了后端代码不生效**：前端 HTML 由后端每次从磁盘读取，但后端逻辑需**重启 `server.py`** 才生效。
- **公网地址打不开**：确认 `start_tunnel.py` 与 `server.py` 两个窗口都未关闭；隧道地址每次重启会变化。
- **导入后提示重复**：系统按「去除空白 + 转小写」后的名称做唯一判定，同名比赛不会重复入库。
